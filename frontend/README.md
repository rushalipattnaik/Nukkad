# Nukkad frontend

This is the React + TypeScript + Vite + Tailwind + Leaflet frontend for
Nukkad. See the **main [README.md](../README.md)** at the project root for
setup instructions, architecture, and everything else.

Quick start (from the project root, after `.\scripts\setup.ps1`):

```powershell
.\scripts\run_frontend.ps1
```

Then open http://localhost:5173. The backend must also be running
(`.\scripts\run_backend.ps1` in a separate terminal).
